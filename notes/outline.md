# 知识框架（草案，待确认）

依据：人教版初中数学新教材目录（国家中小学智慧教育平台）；九年级下册暂按旧教材。写作规则见 [writing-plan.md](writing-plan.md)。

## 编排思路

- **按结构、逻辑和领域分部分。**
- **难度曲线自然：**每部分从具体、直观的内容开始，逐步抽象；整本书先“数”后“形”，最后数形合一。
- **成体系、融会贯通：**讲清一个概念从哪里来、和哪些知识是一体两面。每页设“联系”一节，链接到相关页面，前后都可以链接。
- **每部分先有总览页：**用一张对比表把本部分串起来，当作本部分的地图。
- **与课本对照：**每页注明对应的人教版章节。

## 导读

- **主线：**数 → 式 → 方程与函数；形 → 推理 → 变换；最后数形合一。
- **核心判断：**每个代数关系都有一个几何的样子，每个几何关系都能写成数。
- **框架图：**全书各部分和几条主线的关系。
- **怎么用这份资料：**按部分顺序学；第一部分“数学的语言与推理”是工具，可以穿插着学。

## 贯穿全书的几条主线

| 主线 | 经过的页面 |
| --- | --- |
| 数轴 → 坐标系 → 函数图象 | 有理数（数轴、绝对值是距离）→ 不等式（解集画在数轴上）→ 平面直角坐标系 → 一次、反比例、二次函数的图象 |
| 面积模型 | 整式乘法和乘法公式（拼图验证）→ 因式分解 → 勾股定理（拼图证明）→ 配方法（配成正方形） |

| 对称 | 相反数 → 轴对称与等腰三角形 → 坐标系中的对称点 → 抛物线的对称轴 → 圆的对称性和垂径定理 |
| 比 | 比例 → 相似 → 锐角三角函数（直角三角形边的比）→ 一次函数的 k（倾斜程度） |
| 变化与对应 | 代数式的值 → 函数 → 动点问题 |
